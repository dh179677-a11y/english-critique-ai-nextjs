# EnglishPro Critique AI 使用说明

## 1. 产品定位

EnglishPro Critique AI 是一个面向英语教学场景的双端应用，包含：

- 学生端：上传口语视频、查看 AI 测评报告、完成老师布置的图文导学任务。
- 老师端：创建学生账号、管理班级、查看学生测评记录、上传绘本资料并发布 Storyflow 任务。

当前系统的核心能力集中在以下两条主线：

1. `口语视频测评`
2. `Storyflow 图文导学任务`

## 2. 角色与权限

### 老师端

- 可以通过邀请码注册老师账号。
- 可以创建学生账号，学生不能自行注册。
- 可以创建班级、给学生分班、重置密码、停用或删除学生。
- 可以查看学生上传的视频和测评结果。
- 可以上传图片或 PDF 生成 Storyflow 资料，并发布任务给学生。

### 学生端

- 只能使用老师创建好的账号登录。
- 可以上传自己的口语视频并查看测评报告。
- 可以进入任务列表，完成老师发布的 Storyflow 练习。

## 3. 首次使用流程

### 老师首次开通

1. 打开系统登录页。
2. 点击“老师注册”。
3. 输入老师姓名、登录账号、密码和邀请码。
4. 注册成功后会直接进入老师端后台。

### 学生首次开通

1. 由老师在“学员管理”中创建学生账号。
2. 老师把账号、初始密码和登录地址发给学生。
3. 学生使用老师分配的账号登录系统。

## 4. 老师端使用说明

### 4.1 个人中心

老师登录后进入个人中心，可查看：

- 学员总数
- 班级总数
- 测评记录总数

这里也是进入“学员管理”“班级管理”“图文导学”等核心模块的入口。

### 4.2 学员管理

路径：`老师端 -> 学员管理`

主要功能：

- 新增学生账号
- 设置学生昵称、备注名、性别、生日、年级、学校等信息
- 设置账号有效期
- 为学生分配班级
- 搜索学生
- 筛选状态（使用中、已停用、已过期）
- 重置学生密码
- 启用 / 停用账号
- 删除学生账号
- 批量复制学生登录信息

建议操作顺序：

1. 先创建班级。
2. 再新增学生并分配到班级。
3. 使用“邀请”功能复制学生账号信息，统一发给家长或学生。

### 4.3 学员详情

路径：`老师端 -> 学员管理 -> 点击某个学生`

可查看：

- 学生基本信息
- 历史上传记录
- 每次上传对应的视频
- 每条记录的五维评分
- 整体点评和改进建议

适合用于课后复盘、家长反馈和个别辅导。

### 4.4 班级管理

路径：`老师端 -> 班级管理`

主要功能：

- 创建班级
- 删除班级
- 查看每个班级的学员数量
- 查看班级累计测评记录数
- 进入班级详情页

### 4.5 班级详情

路径：`老师端 -> 班级管理 -> 点击某个班级`

当前可用能力包括：

- 查看班级成员
- 查看班级下学生的测评记录
- 按记录查看视频与评分
- 查看班级排行榜和学习概览

这是一个班级工作台，适合做班级层面的教学追踪。

### 4.6 图文导学 Storyflow

路径：`老师端 -> 图文导学`

这是系统里第二条核心业务线，用来把绘本资料变成可练习、可发布、可点评的任务。

#### A. 上传资料

支持两种方式：

- 上传图片
- 上传 PDF

系统会：

- 把文件上传到腾讯云 COS
- 尝试抽取或识别页面文字
- 自动生成故事标题、摘要、角色、时间地点、关键词
- 自动生成思维导图和逐页看图说话内容

如果不想直接分析 PDF，也可以先创建空白任务，后续逐页补图片和文字。

#### B. 编辑资料

老师可以继续完善：

- 资料标题和摘要
- 角色、关键词、时间、地点
- 思维导图的开头 / 中间 / 结尾
- 每一页的图片和文字
- 影子跟读用的音频
- 脱稿表演任务单内容

#### C. 资料库管理

路径：`老师端 -> 图文导学 -> 整理资料库`

可进行：

- 创建文件夹
- 重命名文件夹
- 删除文件夹
- 调整资料顺序
- 搜索资料
- 按文件夹或分类整理资料
- 修改资料分类

适合老师长期沉淀绘本和任务资源。

#### D. 发布任务给学生

在某份 Storyflow 资料中点击“发布任务”后，可以：

- 选择一个或多个学生
- 把当前绘本任务发布给选中的学生

发布后，学生登录系统，会在“我的图文导学任务”中看到对应任务。

#### E. 影子跟读作业查看与评分

老师可在 Storyflow 中查看：

- 哪些学生已提交影子跟读
- 学生录音
- 系统给出的当前评分
- 老师填写的评语

并支持：

- 试听录音
- 下载音频
- 重新评分
- 保存老师点评

## 5. 学生端使用说明

### 5.1 登录

学生使用老师分配的账号和密码登录。登录后首页会显示两个入口：

- `任务入口`
- `上传口语视频`

### 5.2 上传口语视频

路径：`首页 -> 上传口语视频`

操作步骤：

1. 填写学生姓名。
2. 选择或填写辅导老师。
3. 填写绘本名称 / 内容。
4. 选择作业类型。
5. 上传视频文件。

支持的典型作业类型：

- 绘本跟读
- 看图说话
- 脱稿表演

提交后，系统会自动完成：

- 视频上传
- AI 口语分析
- 生成五维评分
- 生成整体点评、训练建议和语法讲解
- 自动保存到“我的测评记录”

### 5.3 查看测评记录

路径：`首页 -> 我的测评记录`

可以查看：

- 历史测评列表
- 每次测评的综合得分
- 具体到单条记录的完整报告

### 5.4 查看测评详情

路径：`我的测评记录 -> 点击某条记录`

详情页包含：

- 五维评分图表
- 流畅度、发音、语调、词汇、情感表达的分项点评
- 整体点评
- 训练建议
- 语法讲解

当前页面还支持：

- 手动编辑报告内容
- 局部重新点评
- 下载文本版报告
- 导出图片版报告

### 5.5 图文导学任务

路径：`首页 -> 任务入口`

学生会看到老师发布给自己的绘本任务卡片。点击后进入任务详情和练习页面。

系统当前提供 5 个任务模式：

#### 1. 思维导图

- 先看整本故事结构
- 帮助学生理解故事开头、发展和结尾

#### 2. 影子跟读

- 学生先看图片，再对照原文朗读
- 可按页完成录音
- 完成后可形成提交记录

#### 3. 看图说话

- 先只看图片
- 先自己回忆原文
- 想不起来时再逐步领取提示

#### 4. 整本复述

- 结合人物、关键词和思维导图
- 用完整语言复述整本绘本

#### 5. 得分点评

- 查看这本绘本在各项任务中的得分
- 查看老师的点评内容

## 6. 推荐使用流程

### 日常教学闭环

1. 老师注册并进入后台。
2. 创建班级。
3. 创建学生账号并分班。
4. 学生登录后上传日常口语视频，系统生成 AI 测评报告。
5. 老师在学员详情或班级详情中查看学生表现。
6. 老师上传绘本资料到 Storyflow。
7. 老师发布任务给指定学生。
8. 学生在任务入口完成影子跟读、看图说话和整本复述。
9. 老师回到 Storyflow 查看提交情况并补充点评。

### 适合的使用场景

- 绘本跟读作业
- 看图说话训练
- 课后视频打卡
- 口语能力阶段性评估
- 老师布置整本绘本复述任务

## 7. 常见注意事项

### 账号相关

- 学生不能自行注册，只能由老师创建。
- 老师注册需要邀请码。
- 学生密码可由老师后台重置。

### 数据相关

- 学生上传后的测评记录会保存到系统中。
- Storyflow 发布后，学生任务会出现在任务列表。
- 老师可以重复发布不同绘本给同一名学生。

### 使用建议

- 上传视频前尽量填写完整的学生名、绘本名和作业类型，方便后续检索。
- Storyflow 绘本页数建议控制在较合理范围内，便于分析和课堂使用。
- 正式发布给学生前，老师最好先检查思维导图、逐页文字和看图说话提示是否准确。

## 8. 当前核心模块与扩展模块说明

当前已经形成稳定使用闭环的模块主要是：

- 学员管理
- 班级管理
- 口语视频测评
- Storyflow 图文导学

老师端首页中还保留了课程、约课、财务、活动等扩展入口。这些入口更适合作为后续拓展模块理解，日常使用请优先以上面四类核心模块为主。
