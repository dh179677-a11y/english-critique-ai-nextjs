# 看图说话答对后自然推进设计

## 目标

当学生已经说出看图说话当前目标词或目标句时，Mia 必须立即认可并推进学习，不再解释、重复或要求孩子重读已经完成的内容。

## 问题根因

当前看图说话模式虽然包含“说对后直接推进”的规则，但系统级通用教学规则仍允许解释词义、讲发音和安排跟读。模型有时优先采用通用话术，把已经完成的目标当作仍需教学的内容，例如学生说出 `Spots` 后再次解释其含义并要求重读。

## 行为规则

1. 答对当前目标后，只进行一次简短、自然的肯定。
2. 当前页还有未完成的下一句时，紧接着引导下一句，不再讨论刚才已经完成的词或句子。
3. 当前页全部目标已完成时，直接要求学生翻到下一页继续，不询问学生是否愿意继续。
4. 已完成目标禁止：
   - 再次解释词义；
   - 再次讲解发音；
   - 再次示范同一内容；
   - 要求学生重复或重读；
   - 用“你能再说一次吗”“现在试着说对这个词”等话术停留在原地。
5. 当前可信原文支持的常见 ASR 混淆仍视为答对，例如 `Sports` 对应 `Spots`、`beef` 对应 `Biff`、`keeper` 对应 `Kipper`。
6. 回复必须自然承接学生刚才的内容，不能表现得像没有听见学生回答。

## 实现方式

在 `StoryflowTaskPlayer` 生成看图说话 RTC 当前学习状态时，将一组明确的“答对即推进”规则放在看图说话规则末尾，使其成为该模式最近、最高优先级的行为约束。规则包含单目标页面和多句页面的分支，以及 `Spots` 场景的正反示例。

不在前端自动翻页，也不通过字幕相似度直接改变页码，避免 ASR 误识别导致错误翻页。页面仍由学生操作，Mia 负责明确提示下一句或下一页。

## 验证

- 增加结构回归断言，确认看图说话提示词包含“答对后禁止重复”和“当前页完成后直接要求翻页”。
- 增加 `Spots` 示例断言，明确禁止解释词义并再次要求朗读。
- 运行全部 Storyflow 检查、ESLint 和 Next.js 生产构建。

## 非目标

- 不修改语音识别模型或字幕合并逻辑。
- 不由前端自动判断答对或自动翻页。
- 不改变绘本精讲和影子跟读的教学流程。
